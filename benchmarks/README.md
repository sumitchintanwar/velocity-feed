# RTMDS Benchmark Suite

This directory contains the benchmarking and load-testing assets for the Real-Time Market Data System.

## Layout

- `methodology.md`: Detailed breakdown of benchmark methodologies, serialization performance, and latency metrics.
- `scripts/`: Load generation and performance profiling scripts used to saturate the system.
- `reports/`: Aggregated performance reports and metric extractions.
- `raw-results/`: Raw data outputs separated by component (coordinator, broker, publisher, subscriber).

For the broader overview, refer to the root [benchmarks.md](../docs/benchmarks.md).
